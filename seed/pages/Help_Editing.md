How to edit this wiki. **Editing is disabled on the mirror**; this page is kept for completeness.

## Markup

- `''italic''`, `'''bold'''` — the mirror renders the imported pages with a simplified markup, so you will see `*` and `**` in the source view instead.
- `[[Page name]]` links to a page. `[[Page name|label]]` changes the text.
- `== Heading ==` for sections.
- `{{stale}}`, `{{deprecated}}`, `{{archive}}` add the usual banners.
- Sign talk page comments with `~~~~`. On the mirror these appear as `{{sig:name|date}}`.

## Conventions

- Page titles are `Title_Case_With_Underscores`.
- Design pages go in the main namespace. Meeting notes under `Archive:`. Discussion on `Talk:`.
- Do not link to the internal tracker; it will be gone before the link is.
- Every page gets a category. Most pages do not have one.

## Attachments

Upload via `Special:Upload` (disabled). Existing attachments are under `/attachments/`.
